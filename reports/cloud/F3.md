# F3: Self-hosted worker pool, Helm chart and Docker image

## Built

- `internal/dispatch/broker/lease.go`: the leasing side. Hashed pool tokens (`Pools`), a worker registry,
  leases with expiry, re-lease when a worker stops heartbeating (max 3 attempts, then `failed_lost`),
  selection by labels and capabilities, drain, bounded job logs. A stale `Complete` from a lost worker is rejected.
- `internal/worker`: `Plane` (HTTP API with long-poll), `Worker` (outbound-only client: register, lease,
  stream logs, heartbeat, drain on SIGTERM), `ExecRunner` (runs only allowlisted programs, default `factory`).
- `cmd/factory/cmd_worker.go`: `factory worker run | plane | token`. No MCP tool (`noTool`: long-running process).
- `Dockerfile`: static build, distroless `nonroot`, uid 65532. One image for `serve` and `worker`.
- `deploy/helm/factory/`: control plane Deployment and Service, one worker Deployment per pool, ServiceAccount,
  NetworkPolicies (workers: no ingress; plane: ingress from workers only), values for pools, resources, secret refs.

  (regenerated), `README.md` command list, `CHANGELOG.md`, `tools/reach/reach_test.go` (the broker exemption

## Decisions

- Transport is HTTPS long-poll (25 s cap), not WebSocket: plain HTTP works through every proxy.
- The pool comes from the token. A worker cannot claim another pool or use another pool's worker id.
- Tokens are random 256-bit values, so a plain SHA-256 is stored, compared in constant time.
- Job submit and status use a reserved `_submit` pool token, kept apart from worker tokens.
- The control plane runs as `factory worker plane`, a separate process. Mounting the same routes into
  `factory serve` needs an edit to `cmd_serve.go` and `internal/serve`, which I do not own. Left for a follow-up.
- Leases are in memory, so the plane runs one replica. A restart loses queued jobs. A durable store is not built.
- The default runner only runs programs named by `--allow` (default `factory`), so the control plane cannot run arbitrary commands.
- The core planner does not yet submit jobs to the plane; that wiring is outside my paths.
