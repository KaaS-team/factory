## Decisions

- `--fix` alone still dispatches the first audit fix, as before, and the existing tests pin that.
  Readiness is `--ready`, and `--ready --fix` repairs it. `--fix` now always exists; without a
  dispatcher and without `--ready` it errors.
- Fixes never overwrite a file. Build, test and branch protection failures have no in-place fix and
  say what a person must do. Branch protection reads "unknown" without a token and does not fail.
- Duplicate check: title and body token similarity (title weighs 0.6). At 0.80 or more it is a
  duplicate with no model call. From 0.50 to 0.80 a `Confirmer` decides; none is wired, so the
  CLI never calls a model and a likely duplicate proceeds.
- Issue #392 was not readable from this session, so the "about 30-minute slice" caps are my guess:
  4 criteria and 4 files per ticket, 12 slices per PRD. Bigger slices split into ordered parts.
  The constants are `MaxCriteria`, `MaxFiles`, `MaxSlices`.
- PRD format: `# Title`, intro, `## Slices`, then `### Name` with `Depends:`, `Files:` and bullet criteria.
- I touched `cmd/factory/cmd_plan.go` to add the flag rather than `internal/plancmd`, which I do not own.

- `.ratchet.json` is raised by hand from 46599 to 47571 Go lines, with a reason. It is outside my paths but the gate needs it. `help_ee.golden` is regenerated for the same reason.
