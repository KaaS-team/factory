# E1: Identity and RBAC on the ee contract

## What I built

- `ee/authz` (new, `ee` tag): `Authorizer` implements `contract.Authorizer` with the contract's eight rules and `contract.Grants`. `GroupMap` maps IdP group names to role bindings at org, team or repo scope, and `Validate` refuses an unknown role or scope.
- `ee/identity/directory.go`: `Directory` implements `contract.Identity` over a SCIM store. Credentials: OIDC ID token and agent token. A person who SCIM never provisioned is `ErrUnauthenticated`. A person SCIM set inactive, deleted, or `Deprovision` turned off is `ErrDeprovisioned` on the next call. `Session(sso.Session)` turns an OIDC or SAML sign-in into a principal. Bots (per-run agent tokens) are principals of kind bot with the bot role at org scope. A bot stops when its token is revoked, is for another org, or its delegating user is deprovisioned. `Store()` wraps the SCIM store so a SCIM delete is remembered.
- `ee/identity/identity.go`: `Issuer.Check` (verify plus blocklist).
- `ee/sso/verify.go`: `IDTokenVerifier` for bearer ID tokens. `ee/sso/oidc.go`: shared `sessionOf`, and `Session.Subject`.
- `internal/serve/routes.go`: the route table. Every route has an `Action` or an `Open` reason. `internal/serve/auth.go`: `Access` guard (401 unauthenticated, 403 deprovisioned or denied; the body holds only the stable reason code). `Options.Access` turns it on; without it nothing changes.
- `.ratchet.json`: raised by hand, +475 lines, with a reason.

## Decisions

- `ee/authz` carries the `ee` tag like the other ee features, so the conformance command needs `-tags ee`. `ee/notag_test.go` is not mine, so I did not add an untagged exception.
- Principal ids are SCIM resource ids. SCIM is the source of truth: no just-in-time user creation.
- Roles come from the IdP groups claim plus SCIM group membership, through one `GroupMap`.
- `internal/oidc` is untouched. It is the non-enterprise bearer path and still works.

## Left undone

- `factory serve` does not yet build an `Access` from config. That needs a hook in `cmd/factory` (not an owned path): in an `ee` build file, construct `Directory` and set `serve.Options.Access`.
- SAML as a bearer credential returns `ErrUnsupportedCredential`. SAML sign-in works through `Directory.Session`, but there is no session cookie issuer.
- Role bindings are not persisted outside SCIM and the group map. No custom roles, no API tokens.
